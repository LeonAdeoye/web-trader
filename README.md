How to run the app

To build files in the ./build directory run command: **npm run electron:build**

To run the app, run on command line: **npm run electron:serve**

For the backend side, open up wsl or windows powershell then first start AMPS:
bash
cd /mnt/c/AMPS-5.3.3.118-Release-Linux/bin
./ampServer minimal.xml


To start and stop back-end services:
cd /mnt/c/Users/'Leon Adeoye'/development/scripts
./start-all-services.sh

./stop-all-service.sh


To run the app, run on command line: **npm run electron:serve**
